# 엑셀 정리기 — 3주차

## 쓰기 전에

1. **파일은 브라우저를 떠나지 않습니다.** 정리는 모두 이 브라우저 안에서 합니다. F12 → Network 탭을 연 채 파일을 넣어 보면, 파일이 밖으로 나가는 요청이 없는 것을 직접 확인할 수 있습니다.
2. **이 정리기가 못 하는 것:** 처방에 없는 것은 고치지도 표시하지도 않습니다. 출장비정산 정답 대조에서 처음 놓친 22건 중 15건(출장일 빈칸 · 박수 음수와 너무 큰 값 · 교통비 음수 · 부서의 같은 뜻 다른 이름)은 처방을 더해 고치거나 표시하게 했습니다. 남은 7건은 **같은 줄이 덮어쓴 원래 줄**이라 되살리지 못합니다. 또 **표시한 값(빈칸 · 튀는 값 · 칸 사이 모순)은 고치지 않습니다** — 진짜 값은 사람이 확인해야 합니다. 처방 표에 없는 새 이름이 들어오면 그대로 둡니다.
3. **처방을 바꾸려면 `rules/<파일 이름>.json`을 고칩니다.** 코드는 고치지 않습니다.

엉망인 엑셀·CSV를 끌어다 놓으면 **증상을 진단**하고, **내가 정한 규칙**대로 정리하고, **바꾼 것을 한 줄씩** 남깁니다.
**파일은 이 브라우저를 떠나지 않습니다.** 서버가 없습니다.

```
python -m http.server 8000      # index.html 을 더블클릭하면 예시 파일을 못 읽습니다
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `rules/*.json` | ★ **처리 규칙** — 무엇을 어떻게 바꿀지, **왜** 그렇게 정했는지. **사람이 정한다** |
| `clean.js` | 진단(규칙 없이 증상 찾기) · 규칙 적용 · «두 번 돌려도 같은가» · 정답 대조 |
| `app.js` · `index.html` · `style.css` | 화면 |
| `lib/xlsx.full.min.js` | 엑셀 읽기 (SheetJS Community Edition, Apache 2.0 — `lib/LICENSE-sheetjs.txt`) |
| `data/` | 예시 파일 세 개 — 상담이력 · 교육이수로그 · 출장비정산 (모두 만들어낸 데이터) |
| `CLAUDE.md` | 이 프로젝트에서 늘 지킬 것 (저장소에만, 배포 제외) |
| `tools/` | 정답 · 확인 도구 — **저장소에도 배포에도 올리지 않는다** (`.gitignore` · `.vercelignore`) |

## 규칙 파일의 모양

```json
{
  "columns": {
    "채널":   {"trim": true, "map": {"유선": "전화"}, "why": "같은 채널을 여러 이름으로 적었다"},
    "상담시간": {"number": true, "rescale": {"over": 180, "divide": 60}, "why": "…"},
    "이수시간": {"number": true, "missing": "flag", "range": {"min": 0, "max": 400, "action": "flag"}}
  },
  "cross_checks": [{"label": "이수 0시간인데 수료", "when": [["이수시간", "==", 0], ["수료여부", "==", "수료"]]}],
  "duplicates": {"action": "drop", "why": "모든 열이 같은 행은 하나만"}
}
```

- 날짜 칸에 `"unparsed": "flag"`를 더하면 읽지 못한 날짜(연도 두 자리 등)를 고치지 않고 표시합니다.
- `cross_checks`의 조건은 `==` · `!=` · `>` · `<` · `blank`. 한 칸만 넣으면 한 칸 검사(예: 교통비 `<` 0)가 됩니다.

적용 순서는 열마다 `trim → map → blank_to → strip_units → number → date → rescale → missing/range`, 그다음 두 열 검사, 마지막에 중복입니다.

## 확인한 숫자

이 컴퓨터에 node 가 없어 같은 엔진을 파이썬으로 옮겨 센 값입니다 (2026-11-14). 브라우저에서 같은 숫자가 나오는지 확인하십시오.

| 파일 | 줄 | 지운 줄 | 고친 값 | 표시한 줄 | 두 번 돌려도 같은가 |
|---|---|---|---|---|---|
| 출장비정산.xlsx | 201 → 194 | 7 | 20 | 23 | 같음 |
| 상담이력.xlsx | 1,542 → 1,512 | 30 | 2,671 | 0 | 같음 |
| 교육이수로그.csv | 120 → 120 | 0 | 73 | 17 | 같음 |

- 출장비정산 정답 대조 (만든 방법의 섞은 것 47건): **고쳤다 18 · 표시만 했다 22 · 놓쳤다 7**. 놓친 7건은 같은 줄이 원래 줄을 덮어쓴 것 — 원래 값이 파일에 없어 처방으로 되살릴 수 없다
- 출장비정산 마지막 줄(행202)은 만든 방법에도 정답에도 없는 합계처럼 보이는 줄 — 지우지 않고 빈칸 · 숙박비 초과로 표시한다
- 상담이력 · 교육이수로그의 정답 대조(1,482행 일치 · 상담시간 18행 어긋남)는 목업 때 확인한 숫자다. «고친 값»은 쉼표만 뗀 것도 기록하게 바꿔서 예전보다 많을 수 있다

## 도구가 못 보는 것

- **뜻이 같은 다른 말** — «완료»와 «수료». 값 목록을 눈으로 봅니다
- **색으로만 표시된 정보**, 병합 셀, 머리글 두 줄, 시트 여러 개 — 파일을 한 번 열어 봐야 압니다
